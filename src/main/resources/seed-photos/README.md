# Демо-көліктердің фотолары

Осы папкаға фотоларды көліктің **мемлекеттік нөмірі** атауымен салыңыз да, қосымшаны қайта іске қосыңыз — фото автоматты түрде тіркеледі (тек әлі фотосы жоқ көліктерге).
