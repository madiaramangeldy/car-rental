# 4. Тестілеу

## 4.1. Тестілеу стратегиясы

| Деңгей | Құралдар | Не тексеріледі | Файл |
|--------|----------|----------------|------|
| Unit | JUnit 5 | Құнды есептеу, жеңілдіктер, кепілдік | `PriceCalculatorTest` (5 тест) |
| Unit (mock) | JUnit 5 + Mockito | Брондау ережелері, күй ауысулары, IDOR | `BookingServiceTest` (9 тест) |
| Unit (файлдар) | JUnit 5 + `@TempDir` | Фото жүктеу: түрі, көлемі, атауы, path traversal | `ImageStorageServiceTest` (6 тест) |
| Интеграциялық (қауіпсіздік) | Spring Boot Test + MockMvc + spring-security-test | Рөлдер, CSRF, тақырыптар, кіру, суреттер | `SecurityIntegrationTest` (12 тест) |
| Қолмен (функционалдық) | Браузер | Пайдаланушы сценарийлері | 4.3-бөлім |
| Қолмен (қауіпсіздік) | Браузер DevTools, Burp/ZAP (міндетті емес) | Шабуыл сценарийлері | 4.4-бөлім |

Іске қосу: `mvn test` немесе IntelliJ-те `src/test/java` → *Run 'All Tests'*.
