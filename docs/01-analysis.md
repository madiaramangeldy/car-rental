# 1. Талдау: пәндік аймақ және талаптар

## 1.1. Пәндік аймақ

Көлік жалдау компаниясы (прокат) клиенттерге белгілі бір мерзімге ақыға көлік береді. Қолмен жүргізілетін процесс (телефон, Excel, қағаз келісімшарт) мынадай мәселелер тудырады:

- **қос брондау** — бір көлік бір күнге екі клиентке уәде етіледі;
- клиент қай көлік қай күндері бос екенін білмейді, менеджерге қоңырау шалуға мәжбүр;
- құнды есептеу мен келісімшарт толтыру қолмен жасалады → қателер;
- кім қандай әрекет жасағаны тіркелмейді → дербес деректер мен қаржылық ақпарат қорғалмаған.

**Мақсат:** автопаркті, брондауды және келісімшарттарды бір жүйеде біріктіретін, рөлдер бойынша қол жеткізу шектелген қауіпсіз веб-қосымша жасау.

## 1.2. Мүдделі тараптар (актерлер)

| Актер | Сипаттамасы |
|-------|-------------|
| Қонақ | Тіркелмеген пайдаланушы, каталогты қарайды |
| Клиент | Тіркелген, көлікті брондайды |
| Менеджер | Брондарды өңдейді, келісімшарт рәсімдейді |
| Әкімші | Автопаркті және пайдаланушыларды басқарады, аудитті қадағалайды |

## 1.3. Функционалдық талаптар

| ID | Талап | Актер |
|----|-------|-------|
| FR-01 | Тіркелу (аты-жөні, email, телефон, жүргізуші куәлігі, құпиясөз) | Қонақ |
| FR-02 | Email және құпиясөз арқылы жүйеге кіру / шығу | Барлығы |
| FR-03 | Автопарк каталогын көру, санат бойынша сүзу | Қонақ, Клиент |
| FR-04 | Көрсетілген күндерге бос көліктерді іздеу | Қонақ, Клиент |
| FR-05 | Көлік карточкасы: сипаттамасы, бағасы, бос емес күндері | Қонақ, Клиент |
| FR-06 | Көлікті брондау; құн автоматты есептеледі (жеңілдікпен) | Клиент |
| FR-07 | Өз брондарының тізімі және күйлері | Клиент |
| FR-08 | Расталмаған бронды болдырмау | Клиент |
| FR-09 | Барлық брондарды күйі бойынша сүзіп көру | Менеджер |
| FR-10 | Бронды растау → келісімшарт автоматты жасалады | Менеджер |
| FR-11 | Бронды аяқтау (көлік қайтарылды) → келісімшарт жабылады | Менеджер |
| FR-12 | Бронды болдырмау → келісімшарт бұзылады | Менеджер |
| FR-13 | Келісімшартты көру және басып шығару | Клиент (өзінікін), Менеджер |
| FR-14 | Көлік қосу / өзгерту / жою (немесе пайдаланудан шығару) | Әкімші |
| FR-15 | Пайдаланушы рөлін өзгерту, аккаунтты өшіру, бұғаттан шығару | Әкімші |
| FR-16 | Аудит журналын көру | Әкімші |

## 1.4. Функционалдық емес талаптар

| ID | Талап |
|----|-------|
| NFR-01 | **Қауіпсіздік:** құпиясөздер тек BCrypt хэші түрінде сақталады |
| NFR-02 | **Қауіпсіздік:** рөлдік қол жеткізу (RBAC), клиент тек өз деректерін көреді |
| NFR-03 | **Қауіпсіздік:** CSRF, XSS, SQL-инъекция, brute-force шабуылдарынан қорғаныс |
| NFR-04 | **Тұтастық:** бір көлікке күндері қиылысатын брондар болмауы тиіс, параллель сұраныстарда да |
| NFR-05 | **Бақылау:** қауіпсіздікке қатысты барлық оқиғалар аудит журналына жазылады |
| NFR-06 | **Қолайлылық:** интерфейс қазақ тілінде, мобильді экранға бейімделген |
| NFR-07 | **Тасымалдылық:** H2 (әзірлеу) және PostgreSQL (өндіріс) дерекқорларымен жұмыс |
| NFR-08 | **Өнімділік:** беттің жауап уақыты < 1 с (100 көлік, 10 000 брон) |

## 1.5. Бизнес-ережелер

| ID | Ереже |
|----|-------|
| BR-01 | Жалдау мерзімі: 1–30 тәулік. Қайтару күні алу күнінен кейін болуы керек |
| BR-02 | Алу күні бүгіннен ерте емес және 180 күннен кеш емес |
| BR-03 | Бос емес кезеңдер: PENDING және CONFIRMED брондар. Қайтару күні келесі клиент ала алады |
| BR-04 | Құн = тәуліктік баға × тәулік саны − жеңілдік (7+ тәул. — 10%, 14+ тәул. — 15%) |
| BR-05 | Кепілдік = 2 тәуліктің құны |
| BR-06 | Бір клиентте ең көбі 3 расталмаған брон |
| BR-07 | Брон тарихы бар көлік жойылмайды, RETIRED күйіне ауыстырылады |
| BR-08 | Техникалық қызметтегі (MAINTENANCE) көлік брондалмайды |

## 1.6. Ұқсас жүйелерге шолу

| Жүйе | Ерекшелігі | Біздің жобаға алғанымыз |
|------|-----------|-------------------------|
| Ірі халықаралық прокат сайттары (Hertz, Sixt, Europcar үлгісі) | Күн бойынша іздеу, санаттар, онлайн брондау | Күндер бойынша бос көліктерді сүзу, санаттар |
| Жергілікті прокат компанияларының сайттары | Көбіне тек каталог + телефон/WhatsApp | Толық онлайн цикл: брон → растау → келісімшарт |
| Каршеринг қосымшалары | Минуттық тариф, мобильді қосымша | Қолданылмайды — біздің модель тәуліктік жалдау |
